# Fake-News-Detection
A Machine Learning project to detect fake news articles using NLP techniques like TF-IDF and a Passive Aggressive Classifier. Achieves 94% accuracy on real-world news datasets.

Due to GitHub file size limits, dataset is not included here.

🔗 Download the dataset from Kaggle:
https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset

# Make sure Fake.csv and True.csv are in the same folder before running
